# Orsolum Organic Soil — E-Commerce Frontend

Modern, high-performance e-commerce frontend web application for **Orsolum Organic Soil**, featuring authentic Saurashtra cold-pressed G-20 Groundnut Oil, herbal cleaners, cold-pressed soaps, and farm utility essentials.

![Orsolum Logo](public/images/Orsolumlogo.png)

## 🌿 Highlights & Features

- **Heritage Arches Banner**: Inspired by traditional Gujarat architectural motifs with 50+ outlet network and commercial supply arches.
- **Hero Spotlight Card**: Exact recreation of the founder certificate showcase and G-20 15L Tin featured pricing.
- **Authentic Saurashtra Slogan & Pricing**:
  - *"કપાસિયા તેલ નહીં, પરંતુ ઓરસોલમ મગફળીના તેલ પર વિશ્વાસ કરો."*

- **8 Purity & Health Pillars**: Zero chemicals, 100% Saurashtra G20 seeds, low oil absorption, zero cholesterol, and helpline integration.
- **Customer Portal & Dashboard**:
  - Mobile OTP & 1-Click Instant Demo login.
  - Interactive store with pack sizes, stock tracking, and live cart adjustments.
  - Real-time order tracking from Rajkot mill dispatch.
  - Saved delivery addresses and loyalty coin rewards.
- **Expanded Product Catalog**:
  - **Orsolum G20 Groundnut Oil** (15L / 5L / 1L)

  - Free delivery threshold meter (₹999+).
  - Coupon support (`ORSOLUM100`).
  - Multi-step checkout with address form, payment options (COD, UPI QR, Netbanking), and celebratory confetti.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/bhavyarajsinh116/orsolum.git

# Navigate to project directory
cd orsolum

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
